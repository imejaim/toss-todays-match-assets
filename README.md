# Toss Today's Match Assets

Public static image assets for Apps-in-Toss service `오늘의 짝꿍`.

This repository intentionally contains only public image assets used by the Toss app brand/icon, sharing Open Graph image links, and in-app character images.

Primary URLs:

- Icon: `https://raw.githubusercontent.com/imejaim/toss-todays-match-assets/main/public/icon.png`
- Match images: `https://raw.githubusercontent.com/imejaim/toss-todays-match-assets/main/public/match_images/{gender}/{element}_{variant}.png`
